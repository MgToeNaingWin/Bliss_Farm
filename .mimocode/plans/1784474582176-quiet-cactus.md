# Chat System Implementation Plan — Bliss Farm

## Context

Bliss Farm is a Laravel 12 farming/livestock community app (Myanmar) using:
- **Tailwind CSS v4** + Flowbite plugin + Vite
- **Alpine.js** installed globally (`window.Alpine`) but **not used** — all interactivity is vanilla JS
- **Font Awesome 6** (CDN) for icons
- **fetch() API** for AJAX (consistent pattern across news comments/reactions)
- **Blade** layouts: `user.layouts.master` with `@yield('bdy')`, `@extends`
- **Myanmar language** UI
- **No broadcasting infrastructure** — no `config/broadcasting.php`, no `routes/channels.php`, no Pusher, no Events directory
- **Role-based auth**: user/admin/superadmin via middleware

This plan adds a **web-based chat system** using **Laravel Echo + Pusher** for WebSocket-based real-time messaging. The UI uses **vanilla JS + fetch()** to match the existing codebase patterns.

### 2.2 Update `app/Models/User.php`
Add relationships:
```php
public function chats() { return $this->belongsToMany(Chat::class, 'chat_participants'); }
public function sentMessages() { return $this->hasMany(Message::class, 'sender_id'); }

### 3.2 Routes (`routes/chat.php`)
```
Route::middleware('auth')->prefix('chat')->name('chat.')->group(function () {

    POST   /chat                          → store         (create individual chat)
    POST   /chat/group                    → storeGroup    (create group)
    GET    /chat/{chat}                   → show          (chat room)
    POST   /chat/{chat}/message           → sendMessage
    PUT    /chat/message/{message}        → editMessage

    POST   /chat/message/{message}/forward → forwardMessage
    POST   /chat/message/{message}/react  → toggleReaction
    POST   /chat/{chat}/participants      → addParticipant
    DELETE /chat/{chat}/participants/{user} → removeParticipant
    PUT    /chat/{chat}/mute              → toggleMute
    PUT    /chat/{chat}/pin               → togglePin

    GET    /chat/search                   → search
    GET    /chat/contacts                 → contacts

    POST   /chat/{chat}/typing/stop       → typingStop

## Phase 7: Real-Time via WebSockets (Laravel Echo + Pusher)

### 7.1 Install dependencies
```bash
composer require pusher/pusher-php-server
npm install laravel-echo pusher-js
```

### 7.2 Configure broadcasting
- Create `config/broadcasting.php` (Pusher config)
- Update `.env`:
  ```
  BROADCAST_CONNECTION=pusher
  PUSHER_APP_ID=your_app_id
  PUSHER_APP_KEY=your_app_key
  PUSHER_APP_SECRET=your_app_secret
  PUSHER_APP_CLUSTER=mt1
  VITE_PUSHER_APP_KEY=${PUSHER_APP_KEY}
  VITE_PUSHER_APP_CLUSTER=${PUSHER_APP_CLUSTER}
  ```
- Update `bootstrap/app.php` to add channels routing

### 7.3 Broadcast channels (`routes/channels.php`)
```php
Broadcast::channel('chat.{chatId}', function ($user, $chatId) {
    return $user->chats()->where('chat_id', $chatId)->exists();
});
```

### 7.4 Events (6 files in `app/Events/`)

| Event | Broadcasts On | Channel | Payload |
|-------|--------------|---------|---------|
| **NewMessage** | Message model | `chat.{chatId}` | message, sender, chat |
| **TypingStarted** | User | `chat.{chatId}` | user_id, user_name |
| **TypingStopped** | User | `chat.{chatId}` | user_id |
| **MessageStatusUpdated** | MessageStatus | `chat.{chatId}` | message_id, user_id, status |
| **MessageReactionEvent** | MessageReaction | `chat.{chatId}` | message_id, emoji, user, action |
| **MessageDeleted** | Message | `chat.{chatId}` | message_id |

### 7.5 Client-side listeners (`resources/js/chat-realtime.js`)
```javascript
import Echo from 'laravel-echo';
window.Echo = new Echo({
    broadcaster: 'pusher',
    key: import.meta.env.VITE_PUSHER_APP_KEY,
    cluster: import.meta.env.VITE_PUSHER_APP_CLUSTER,
});
// Listen on chat channel
window.Echo.private(`chat.${chatId}`)
    .listen('NewMessage', (e) => { /* append message */ })
    .listen('TypingStarted', (e) => { /* show typing */ })
    .listen('TypingStopped', (e) => { /* hide typing */ });
```

### 7.6 Typing indicator
- User starts typing → POST /chat/typing/start
- User stops typing → POST /chat/typing/stop
- Server broadcasts TypingStarted/TypingStopped events

### 7.7 Online status
- On page load: POST /chat/status/online
- Before unload: POST /chat/status/offline
- Store `last_seen_at` in `user_online_statuses` table

1. **Laravel Echo + Pusher** — proper WebSocket real-time messaging
2. **Vanilla JS** — matches existing codebase (no Alpine.js usage despite it being installed)
3. **Emerald/amber theme** — consistent with Bliss Farm design language
4. **Myanmar language** — all UI text in Myanmar, matching existing patterns
5. **Existing `public` disk** — files in `storage/app/public/chats/`
